# 🏥 СУВИЛЛЫН ЗАХИАЛГА УДИРДЛАГЫН СИСТЕМ (СҮУЗС)

> Ананд Хужирт сувиллалд зориулсан вэб суурьтай захиалга болон удирдлагын систем

---

## 📌 Төслийн тухай

**СҮУЗС** (Сувиллын Үйлчилгээний Удирдлага, Захиалгын Систем) нь Өвөрхангай аймгийн Хужирт сумын **Ананд Хужирт сувиллал**-д зориулан хөгжүүлсэн вэб суурьтай захиалга болон захиалгын удирдлагын систем юм.

Өнөөгийн утсаар захиалга авч, цаасан дээр тэмдэглэдэг уламжлалт үйл явцыг орлуулан:

- Амрагч онлайнаар захиалга өгөх
- Админ захиалгыг хянах, баталгаажуулах
- Сарын болон нийт орлогын тайлан гаргах

боломжийг нэг системд нэгтгэн шийдсэн.

---

## ⚙️ Ашигласан технологи

| Давхарга | Технологи |
|---|---|
| Frontend | Next.js 14 (App Router, Server Components), TypeScript, Tailwind CSS |
| Backend | Next.js API Routes (REST), NextAuth.js (JWT) |
| ORM | Prisma ORM |
| Өгөгдлийн сан | PostgreSQL |
| Хөгжүүлэлтийн DB | Supabase |
| Үйлдвэрлэлийн сервер | AWS EC2 + RDS |
| Төлбөр | QPay |
| Тест | Postman (API), k6 (ачааллын тест) |

## 🚀 Суулгах болон ажиллуулах заавар

### Шаардлага

- Node.js 18+
- PostgreSQL (эсвэл Supabase account)
- npm эсвэл pnpm

### 1. Repository clone хийх

```bash
git clone https://github.com/<your-username>/suvilal-booking.git
cd suvilal-booking
```

### 2. Dependencies суулгах

```bash
npm install
```

### 3. Environment хувьсагч тохируулах

`.env` файл үүсгэж дараах утгуудыг бөглөнө:

```env
DATABASE_URL="postgresql://..."
NEXTAUTH_SECRET="your-secret-key"
NEXTAUTH_URL="http://localhost:3000"
QPAY_CLIENT_ID="..."
QPAY_CLIENT_SECRET="..."
```

### 4. Өгөгдлийн сан migrate хийх

```bash
npx prisma migrate dev
npx prisma db seed
```

### 5. Хөгжүүлэлтийн горимд ажиллуулах

```bash
npm run dev
```

Браузерт `http://localhost:3000` нээнэ.

### 6. Үйлдвэрлэлийн build

```bash
npm run build
npm start
```

## 🗂️ Үндсэн функцуудын жагсаалт

### 🌐 Амрагчийн хэсэг (Guest Portal)

- Өрөөний төрөл, байршил харах
- Нэвтрэлтгүйгээр (guest checkout) онлайн захиалга өгөх
- QPay-р урьдчилгаа төлбөр төлөх
- Захиалгын баталгаажуулалт (SMS / имэйл)

### 🖥️ Админ хяналтын самбар (Admin Dashboard)

- **Dashboard** — өнөөдрийн захиалга, орлого, өрөөний ашиглалтын хэмжүүр
- **Захиалга** — захиалгын жагсаалт, хайлт, шүүлтүүр; гараар захиалга нэмэх (walk-in / утсаар); хоёр үе шаттай check-in (1. захиалгын мэдээлэл → 2. амрагчийн дэлгэрэнгүй)
- **Тайлан** — сарын болон нийт орлогын тайлан, хугацааны шүүлтүүр, PDF экспорт

### 💳 Төлбөрийн удирдлага

- Нэг захиалганд олон төлбөрийн хэлбэр дэмжих: CASH, CARD, BANK, QPAY
- Төлбөрийн түүх харах
